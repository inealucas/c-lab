# 🏗️ C-Lab

> Code and exercises in C — exploring low-level systems programming and fundamental computer science concepts.

---

## 📖 About

This repository contains a collection of **C programs**, **exercises**, and **learning projects** focused on:

- **Systems Programming**: Memory management, pointers, and low-level abstractions
- **Data Structures**: Arrays, linked lists, trees, and more
- **Algorithms**: Sorting, searching, and optimization techniques
- **Unix Philosophy**: Understanding how systems work beneath the surface

## 🛠️ Building & Running

### Prerequisites
- GCC or Clang compiler
- Make (optional, for build automation)
- Linux/Unix environment

### Compilation

```bash
# Compile a single file
gcc -o program program.c

# With debugging symbols
gcc -g -o program program.c

# With warnings enabled (recommended)
gcc -Wall -Wextra -o program program.c
```

### Running

```bash
./program
```
